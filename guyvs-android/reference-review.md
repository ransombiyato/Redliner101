# GuyVs Public Video Reference Review

The public Spenn Guy Simulation references were reviewed as a design study, not as material to reproduce. The recurring strengths are a stable, high-contrast arena frame, immediately legible opponent placement, a single obvious focal interaction, slow-to-fast escalation, and visually unmissable impacts or transitions.

## Transferable patterns

| Reference pattern | Original GuyVs translation |
| --- | --- |
| Fixed wide framing with clear arena boundaries | A full-width battle stage with a restrained HUD outside the action space. |
| Strong matchup read before action | A dedicated versus-intro card that shows two fighter cards, colors, and the selected arena. |
| Character silhouette remains visible | Original geometric fighter bodies with separate high-contrast accent and name badge treatments. |
| One dominant force or event per moment | A readable event feed that announces a collision, power move, zone effect, or knockout. |
| Gradual escalation followed by a clear payoff | A short pre-round countdown, intensity escalation, impact emphasis, and an explicit winner/replay end state. |
| Motion and impact communicate force | Original scale pulse, trail, arena shake, and hit-spark effects generated inside GuyVs. |

## Non-goals

GuyVs will not copy the source creator's cutout images, channel handle, titles, audio, exact scenarios, or visual branding. The remake will use the transfer principles above to make a distinct configurable physics sandbox with clearer player control.

## Current GuyVs gap assessment

| Current surface | Gap | Remake priority |
| --- | --- | --- |
| Battle stage | Current lettered circles in a box do not read as characters or establish a matchup before motion starts. | Highest: add original multi-part Guy silhouettes, a versus preview, a clear stage boundary, and an uncluttered event layer. |
| Round flow | The simulation begins immediately and exposes controls before a viewer has an expectation of what will happen. | Highest: add an explicit setup card, countdown, live intensity state, knockout result, and one-tap replay. |
| Impact communication | A border-color change is too subtle to carry the force of a collision. | Highest: add a visible impact burst, shake pulse, collision callout, streaking, and stronger health response. |
| Arena influence | Arena geometry and zones are stored but the battle stage does not visually or physically communicate them. | High: show the selected arena color and boundary first, then progressively add zone and shape behavior. |
| Fighter setup | The creator workflow exposes many tools before making the immediate matchup obvious. | High: provide a simple "pick two, pick a ring, run it" path before advanced editing. |
